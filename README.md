## Features

Fitur untuk Muzakki:
- Daftar Instan: Mempermudah proses administrasi dan pendaftaran dengan menggunakan KTP.
- Chatbot Zaki: Mempermudah perhitungan dan pembayaran zakat serta harmonisasi pengelolaan pajak dan zakat.
- Telusurin: Memperjelas transparansi zakat yang dibayar dan memperkuat akuntabilitas dari Muzakki.
- Arahin: Mempermudah Muzakki dalam menelusuri lokasi terdekat untuk membayar zakat.

Fitur untuk Amil:
- Catetin: Membantu Amil dalam proses pencatatan dan dokumentasi pembayaran zakat.
- Beranda Si Amil: Membantu Amil dalam proses perencanaan pengumpulan dan penyaluran zakat serta proses proyeksi zakat
